## 📁 Featured Projects

### HealthStat: Healthcare Analytics Dashboard

**Objective**: Comprehensive analysis of healthcare operations, patient demographics, disease patterns, and financial performance.

**Key Features**:
- Patient demographics and admission trend analysis
- Disease severity and prevalence tracking
- Financial performance and cost optimization insights
- Hospital resource utilization metrics

**Dashboards Included**:
1. **General Overview** - High-level KPIs and hospital performance metrics
2. **Patient Demographics & Admissions** - Age, gender distribution, and admission patterns
3. **Diseases & Severity Analysis** - Disease prevalence and severity tracking
4. **Financial & Cost Analysis** - Revenue trends, cost per patient, and billing insights

**Tools & Techniques**:
- Tableau Desktop for dashboard creation
- Data cleaning and preparation
- Interactive filters and parameters
- Calculated fields for advanced metrics
- Visual best practices for healthcare analytics

   - Read project reports for detailed analysis and insights
